About the prototype

Designed to assist judgement,
not replace it.

ScamLens SG is an individual PE6201 End-of-Course Project focused on explainable, uncertainty-aware scam risk assessment for Singapore residents.

Scope

Four primary categories

Government official impersonation, investment, job and e-commerce scams. Phishing, credential theft, urgency and payment requests are modelled as cross-cutting mechanisms.

Local foundation

Auditable analysis first

A TF-IDF Logistic Regression classifier estimates risk and scam type. Safety rules, static URL inspection, retrieval and intervention remain separate modules with visible intermediate results.

Optional LLM

A second opinion, not the authority

The LLM receives a compact evidence-grounded context only when explicitly enabled. Conservative fusion can raise concern but cannot downgrade a local high-risk or user-harm decision.

Evidence grounding

Singapore guidance with provenance

A stage-aware weighted lexical retriever ranks 24 purpose-specific chunks from 12 official source pages and displays source dates, verification dates and match reasons. Retrieval supports explanation and does not independently set the local risk score.

Responsible use

Uncertainty and privacy stay visible

Local mode sends nothing to an external AI provider. LLM mode sends a redacted, compact context through OpenRouter, never opens submitted URLs, stores no raw messages in telemetry and always presents a non-definitive assessment.

Developer mode

Built for measurable trade-offs

A one-click diagnostics workspace exposes model selection, local and LLM decisions, fusion reasons, RAG ranking, URL signals, fallbacks, latency, tokens and estimated cost without displaying the API key.
