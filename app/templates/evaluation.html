Current dual-mode system

What is deployed now?

  • Local TF-IDF Logistic Regression remains the default assessment path
  • The LLM second opinion is explicitly enabled per assessment and fails back to local analysis
  • Conservative fusion prevents an LLM from downgrading local high-risk or user-harm decisions
  • Three allowlisted models can be compared only in developer mode
  • Operational runs are stored in local SQLite using message hashes rather than raw messages
  • Labelled benchmarks automatically calculate quality, safety, latency, token and cost metrics
  • LLM outcome metrics are not claimed until the controlled benchmark is completed

Post-review mitigation

What changed after human error review?

  • An explicit off-platform marketplace payment request can no longer receive low-risk reassurance
  • Scam type uses auditable context rules with the trained classifier as fallback
  • All automated regression tests pass
  • The post-review gold run is a diagnostic, not a new independent test result
  • A new untouched evaluation set is required before claiming generalisation
